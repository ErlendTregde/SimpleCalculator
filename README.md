# Simple Calculator

This project is a basic calculator application built using the .NET framework. It adheres to the **Model-View-Controller (MVC)** architectural pattern to ensure clean separation of concerns, making the codebase more maintainable and scalable.

## Features
- **Basic arithmetic operations:** Add, subtract, multiply, and divide.
- **Responsive user interface:** Built with the MVC pattern to separate logic from presentation.
- **Clear and modular code structure:** Ensures that changes in business logic or UI can be done independently.

## Architecture
This project follows the **MVC pattern**:
- **Model:** Contains the core logic of the calculator, such as handling arithmetic operations.
- **View:** Responsible for displaying the user interface and output to the user.
- **Controller:** Acts as the intermediary between the model and view, handling user inputs and updating the view accordingly.

## Technologies Used
- **.NET Framework:** Provides the foundation for building the application.
- **C#:** The programming language used for all backend logic.
- **MVC Pattern:** To keep the code modular and maintainable.

## How to Run the Project
1. Clone this repository to your local machine:
    ```bash
    git clone https://github.com/ErlendTregde/SimpleCalculator.git
    ```
2. Open the project in Visual Studio or your preferred .NET development environment.
3. Build and run the project.
